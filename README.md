# Nautica - Real-Time Beach Information App

Nautica is a mobile application designed to provide real-time beach information across India. With interactive features like live data updates, heatmaps, and safety alerts, Nautica helps users make informed decisions about their beach visits.

## Features

### 🌊 Real-Time Beach Data
- Get up-to-date information about beaches in India.
- Data sourced from **Indian National Centre for Ocean Information Services (INCOIS)**.

### 🗺️ Interactive Beach Map
- Visualize beach readiness and suitability scores using heatmaps.
- Includes **color-coded suitability scores** for clear and distinct representation.

### 🔔 Location-Based Alerts
- Receive **real-time safety alerts** for nearby beaches.
- Alerts include weather warnings, high tides, and other critical information.

### 📊 Weather Integration
- View detailed weather data such as:
  - Temperature
  - Sunrise and sunset times
  - Weather conditions
  - Suitability percentage for beach activities

### 🏖️ Beach Activity Suitability
- Determine if a beach is ideal for activities like swimming, surfing, or sunbathing based on weather and environmental data.

## Technology Stack

### 🌐 Frontend
- **Kotlin**
- Android Studio for app development

### ⚙️ Backend
- Data sourced from **INCOIS API**

### 📍 Mapping
- Heatmap integration for location-based suitability representation

## Usage
1. Launch the app.
2. Use the **search bar** to locate a beach.
3. View **real-time data** and explore suitability heatmaps.
4. Enable location services to receive **alerts** for nearby beaches.
